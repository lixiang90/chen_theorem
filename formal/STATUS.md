## 已补完：Rosser 有限筛系数构造

随后继续构造了实际筛系数，并修正了前述下筛性质的适用范围。
`IsLowerMoebius P mu` 现在只要求对 `n ∣ P` 成立。原先要求对所有自然数
成立的版本过强：如果下筛系数在 1 处为 1 且支集有限，取支集以外的素数
就不可能满足那个全局条件。有限筛实际只需要在筛素数乘积的因子上成立。

新增三个模块：

| 模块 | 已证明内容 |
| --- | --- |
| `LinearSieve/Rosser.lean` | 有限 Buchstab 恒等式、交替上下界递归、显式素因子串展开、展开一致性、严格递减与无重复、乘积低于 `D`、唯一分解与算术系数的绝对值及支集界 |
| `LinearSieve/RosserWeights.lean` | 算术系数和与素因子串的重编号、整除指标上的精确求值、局部下 Moebius 与全局上 Moebius 性质、`exists_rosser_sieve_weights` |
| `LinearSieve/RosserSieve.lean` | 任意乘法密度的主项等于递归多项式、构造出的上下筛权应用于 `BoundingSieve`、余项归约到 `1 ≤ d ≤ Q` 的无权误差和 |

这里采用三次截断的 Rosser 递归。下分支在剩余水平 `D ≤ z²` 时取零；
选择因子 `p` 后该条件变为 `p³ ≥ D`。系数由实际有限递归构造，
不存在“假设筛权存在”的新信任边界。精确主项仍保留为 `rosserEval`，
没有把所需的渐近估计作为已证结论。
数学构造可对照 [Tao 的筛法讲义，组合筛及 beta 筛部分](https://terrytao.wordpress.com/2015/01/21/254a-notes-4-some-sieve-theory/)。

`propext`、`Classical.choice`、`Quot.sound`。

对每个递归项 `f_(n+2)`，已证明全部正参数处的左导数。低于其下截断点时，
`s f_(n+2)(s)` 是常数；高于截断点时，其导数是 `-f_(n+1)(s-1)`。
对应的跳跃源项可积。由于 `log D/log t` 严格递减，这个左导数经复合成为
素数大小变量中的右导数，恰好适用新的 Abel 公式。

因此，令 `s=log D/log z`，在 `s≥cutoff(n+3)` 时已证明

```text
Σ_(w<p≤z) f_(n+2)(log D/log p - 1) · ν(p)V(p)/V(z+1)
  ≤ f_(n+3)(s) + 2K f_(n+2)(s-1)/log w.
```

该结论对所有 `n≥0` 使用同一个密度常数 `K`，允许子项的下截断点落在积分区间内部，
也允许父参数等于其下截断点。证明先给出精确连续积分及非负终端尾项，再舍去尾项。
这里没有离散子状态估计假设。

这一步还没有完成全部停止深度的比较；首项拼接与离散误差的单步传播见下一节，
随深度增长的统一控制与最终累积仍需处理。新增 18 项内核检查通过，
完成本节时 `AuditSieve.lean` 共 361 项，全部仅依赖三个标准公理。

## 已完成：首项拼接、离散误差传播与第二层显式比较

新增 `BuchstabFirstTerm.lean`、`RosserDepthComparison.lean`、

```text
relativeStoppingMass(P,2,z+1,false,D)
  ≤ f_2(s) + 2K f_1(s-1)/log w

```

结论对所有有限奇素数集合统一成立，不再含子状态假设。证明也处理了子截断点
`p` 与首层定理中 `z+1` 的差异，利用连续首项的单调性完成转换。
第二层的统一小误差形式现已在下一节完成；

## 已完成：第二层停止项的统一连续比较

新增 `RosserSecondUniform.lean`。取 `w=D^(1/8)`，已在 Lean 中证明：

- `w^8=D`、`log w=log D/8`，且 `w` 趋于无穷；
- 大 `D` 下，`floor(w)^4<D`，因此第二层小素数前缀为零；

所得最终结论为

```text
∀ ε>0, eventually D, ∀ z≥2, ∀ finite sets P of odd primes,
  relativeStoppingMass(P,2,z+1,false,D) ≤ f_2(log D/log z) + ε.
```

对所有 `p≥3` 统一成立。

该结论完成了实际第二层离散停止项的统一比较，但尚未推广至所有深度。
高阶上筛在小参数区间的转移现已在下一节完成；

## 已完成：任意固定上筛深度的小参数转移
